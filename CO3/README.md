# NLP Lab Programs — Questions 22–32

Install the dependency for the program you want to run:
- 22: `pip install tensorflow numpy`
- 23: `pip install numpy`
- 24: `pip install transformers datasets evaluate torch accelerate`
- 25–27, 29–30: `pip install transformers torch`
- 28: `pip install transformers torch sentencepiece`
- 31–32: `pip install scikit-learn`

Example: `python 23_attention.py`

Transformer models may download files from Hugging Face the first time and need an internet connection. The sample datasets are for demonstration; replace them with your own data for a real evaluation.
